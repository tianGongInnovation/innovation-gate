# 决策规则速查 — 创新之路（创新实践方法论语料集）

| 能力 | 一句话规则 |
|---|---|
| 创新三要素判定器 | 成熟的东西、真实的需求、具体的行动，三把尺子逐一量，缺任何一项就不是创新。 |
| 创新与创造分野定位 | 从无到有是创造（拿奖、院所的事），从有到用是创新（赚钱、企业的事）；先定方向再使劲。 |
| 理论再认识推理法（六步） | 行业说"到头了"时，回理论原文分离后人附加语，用时代条件差找切入点，数值验证后再跨界平移成熟技术。 |
| 创新项目筛选器 | 先负面清单排雷（命中两条即出局），再核三特征（成熟/紧迫/短期出结果），最后十条规则定合作——需求不真一票否决。 |
| 企业节能创新点调研七步法 | 选对企业（四条件缺一不谈）→摸清能量流向→抓占比最大的环节→跳出专家定式→EMC配资本→一线交流定思路→节能必须节钱才算数。 |
| 技术方-企业合作落地流程 | 先核三前提（一把手/资金/执行力，缺一不谈），再按六步推进（考察→赴企→一线沟通→出多方案→企业拍板→起草协议），差旅费对方出。 |
| 企业创新经营诊断 | 用传统经营vs创新经营七区别和自然经济14表现逐条对照企业，命中最集中的观念类型就是主病灶。 |
| 真假需求鉴别 | 能签单、能控制、能落地的才是真需求；看得见抓不住的是假需求，长官意志是主观需求，绕一层的是间接需求。 |
| 创新方法工具箱（八法清单） | 遇到具体卡点先别重造轮子：洋为中用、他山之石、继承发扬、偷工减料降本、回到初心、与时俱进、别怕专家、见多识广，八法对号选。 |
| 成果转化获利与退出结构 | 技术入股不建厂，搭车现有企业体系变现；居间费或干股谢中间人；回购条款先写好，好合好散。 |
| 孵化园/离岸中心运营模式 | 没有自有项目的平台只是二房东（95%死掉）；自带金蛋技术入股，股权前期技术、中期投资人、后期团队说了算。 |
| 合作协议条款审查清单 | 出资方式、筹办垫付、治理分工、资金授权、利润分配、增资稀释、优先购买、终止退出、对外合作优先权——12 类条款逐类核。 |
| 技术交流留痕规则 | 录音留底不用文字电话，按现状/不足/目标/方法/问题清单五段描述，涉密内容不看不听不说不传。 |
| 创新能力三支柱评估 | 知识面广（成熟技术）、社会实践丰富（懂真需求）、动手执行力强，三支柱缺一就落不了地。 |
| 市场导向经营决策 | 方向决策先摆正市场与企业/资金/资源/技术/生产五组关系，再过定位三句话（适合我、投入产出比最大、最有前景缺一不可），四可行性市场排第一。 |
| 兼并重组决策审查 | 并购方案先过三原则（市场导向1+1>2、自愿、法治规范），再扫七误区，最后算全成本（进入+运行+退出，标的价≠成本）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应模块。
