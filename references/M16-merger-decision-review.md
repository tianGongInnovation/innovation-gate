## R — 原文 (Reading)

> 合并兼并必须以市场为导向，通过一加一大于二实现资本的最大增值。市场为导向是前提，一加一大于二是基本方向条件，资本最大增值是目的，这三句话缺一不可。……如果对，那就是可以的；如果不是这样，那是错误的。这一条最最重要，大家千万牢记。
>
> — 秦骏伦，《创新经营》第11讲（11.md，语音转录稿）

---

## I — 方法论骨架 (Interpretation)

这是秦骏伦《创新经营》教程（约2000年）的并购审查框架，在本书作者《创新之路》文集中属辅线：它不教你找项目，而是给一份已经摆上桌面的兼并/重组/扩张方案做"能不能批"的审查。

审查结构是三道闸加一本账：

1. **三原则核对**（11讲）：①市场导向——通过一加一大于二实现资本最大增值（前提/方向/目的三句缺一不可）；②企业行为、自愿结合——强扭的瓜不甜，政府拉郎配埋不稳定因素；③法治化规范化——债务、产权、员工、税收、社保逐项按规范办，法律顾问全程参与。三原则缺任何一条，方案不成立。
2. **七误区扫描**（11/12讲）：①兼并是资本主义丑恶现象论；②被兼并=败家子论；③只有亏损企业才被兼并论；④低成本扩张论（标的便宜≠成本低）；⑤"政府说了算"或"政府不得干预"两个极端；⑥一山不容两虎（为面子位子拒绝联合）；⑦片面追求资产增值而非资本增值（收法人权拼规模，铁索连船，周瑜一把火全完）。命中任何一条，方案背后就有错误动机在驱动。
3. **标的选择**：吃休克鱼（肌体好、暂时缺血缺氧，注入机制就能活），不吃腐烂鱼（烂透了，吃了自己也得死）。
4. **全成本一本账**（12讲）：兼并总成本 = 进入成本（标的价）+ 运行成本（技改投入、承担债务、人员安置）+ 退出成本（吃错了退出的代价）。标的甚至可以接近零，但成本绝不可能是零——"低成本扩张"只算了第一本账。

配套参考：康佳牡丹江"部分兼并"（留债留人、择优而取）、福田模式（参股-控股-股份制梯次组合，以小资本撬动大资产）作为渐进式路径样板。

## A1 — 应用示例 (Application Example)

### 示例 1: 海尔"吃休克鱼"——兼并18家亏损企业一年全部扭亏
- **类型与来源**: 秦骏伦转述案例（reported_case），《创新经营》第2讲、第12讲（02.md、12.md）
- **问题/输入**: 海尔要扩张，面对一批濒临倒闭的亏损企业标的
- **方法论的使用**: 标的选择只吃休克鱼——这些企业硬件完好（肌体好）只是经营昏迷；注入的不是大资金而是商号、商标、机制、管理（无形资产），运行成本被压到最低；符合三原则第①条（一加一大于二、资本最大增值）
- **结论**: 休克鱼+无形资产注入是低成本且真实增值的兼并模式
- **结果**: 兼并18家亏损企业，一年之内全部扭亏为盈（原书所述）

### 示例 2: 康佳部分兼并牡丹江电视机厂——反"低成本扩张"与"整体吞下"的样本
- **类型与来源**: 秦骏伦转述案例（reported_case），《创新经营》第11讲（11.md）
- **问题/输入**: 牡丹江电视机厂盼整体兼并，但背负5000万债务和老弱病残员工；康佳是全国彩电老二也背不动
- **方法论的使用**: 放弃"整体兼并"（没有现实性），改为部分兼并：1800万择优而取（好资产、骨干员工），债务留牡丹江，市政府配合停息挂账；相比自建产能（一个亿投资、四年、无熟练员工），进入成本与周期大幅下降
- **结论**: 部分兼并比整体兼并、比基建扩张都高明；政府可以干预，但干预必须符合三条经济原则（此处是促成而非拉郎配）
- **结果**: 方案获牡丹江市政府批准实施（原书所述；后续经营结果未展开）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个模块？

1. 用户所在企业收到一份兼并/收购/合并提案（自己收购别人，或被别人收购），需要在董事会/办公会前做系统性审查
2. 政府或集团层面在撮合企业重组，用户怀疑是"拉郎配"或"为消灭亏损指标而拼盘"，需要判据来支持或反对
3. 用户看到"低成本扩张""零元收购""蛇吞象"式方案宣传，想核实标的价格之外还藏着哪些成本
4. 企业在做多元化/规模扩张，用户在"自己建厂、收购现成企业、参股联盟"三条路径之间选择
5. 顾问/投资人帮客户做并购尽调，需要一份动机-成本双维度的审查清单补充财务尽调

### 语言信号 (用户的话里出现这些就应激活)

- "这个并购/兼并/收购方案靠不靠谱" / "M&A review / merger decision"
- "要不要收购这家厂 / 这家公司" / "acquire or not"
- "政府撮合我们两家合并，该不该接" / "forced merger"
- "标的很便宜，能不能抄底"（警惕低成本扩张论）
- "重组方案帮我审一下" / "restructuring review"
- "自建产能还是收购现成的" / "build vs buy"

### 与相邻模块的区别 

- 与 M15 市场导向经营决策（U16）的区别: U16管一般经营方向决策（做什么、怎么定位、市场优先性）；本模块是U16在**兼并重组这一特定资本动作**上的特化，多了三原则、七误区、全成本三件专门工具。并购方案先过U16的市场导向性，再过本模块的专门审查。
- 与 M14 企业创新经营诊断（U15）的区别: U15诊断企业经营观念（含"诸侯经济/家族经济"等导致拒绝联合的病），是病因层；本模块审具体交易方案，是动作层。诊断发现"一山不容两虎"观念时，正好对应本模块七误区第⑥条。
- 与本书作者线项目筛选器的区别: 本书作者筛的是短平快技术创新项目（投小钱、快见效）；本模块审的是资本层面的企业级重组（大额、长周期、不可逆性强）。两者规模与可逆性假设完全不同，不可互相套用标准。

## E — 可执行步骤 (Execution)

**必需输入**: 待审方案的核心要素：标的对象（资产/负债/人员/经营状况）、交易方式与价格、合并后的整合计划、方案的发起方与动机背景。缺少标的的负债与人员安置信息时必须索取——这正是"全成本"最容易被隐藏的部分，不能只看收购价格。
**交付物与完成标准**: 一份审查报告：三原则逐项结论 + 七误区命中情况 + 全成本核算提示清单 + 明确审查结论（通过/有条件通过/否决）+ 条件或整改建议。完成标准：每项结论有方案原文或数据作证据；"全成本"三笔账每笔都列出已知项与未知项。

被路由到本模块后，按以下步骤执行：

1. **三原则核对**
   - ①市场导向：方案能否说清"一加一大于二"具体大在哪里（市场/渠道/产能/品牌互补）？目的是资本最大增值还是规模数字？
   - ②自愿性：双方是否真实自愿？是否存在行政撮合痕迹？
   - ③规范性：债务处理、产权归属、员工安置、税收社保是否有规范安排与法律支持？
   - 完成标准: 三条各有"符合/不符合/证据不足"结论与证据
   - 判停条件: 第①条不符合（说不出1+1>2的增值逻辑）→ 直接出具否决结论，不再继续

2. **七误区扫描**
   - 逐条核对方案的论证语言与动机：是否在用"标的便宜"论证（误区④）？是否政府为消灭亏损指标撮合（误区⑤）？是否只为拼规模收法人权（误区⑦）？是否因面子位子拒绝本应做的联合（误区⑥）？
   - 同步判定标的是休克鱼还是腐烂鱼：肌体（资产、团队、产品）是否健康，只是暂时缺血？
   - 完成标准: 七条全部判定；命中任何一条即写明"该误区如何扭曲了方案"，并判定标的质量类别

3. **全成本核算提示**
   - 列三本账：进入成本（收购价、交易费用）、运行成本（技改投入、承接债务、人员安置、整合期管理成本）、退出成本（整合失败时的处置代价）
   - 对照负债临界点做风险提示（一产20%/二产50%/三产70%，2000年前后经验参考值，须按企业资金周转与还债能力具体研究，不作硬性判据）
   - 给出路径建议：能否用部分兼并（康佳模式）、参股-控股梯次（福田模式）或"先合作后兼并"渐进方式降低全成本
   - 完成标准: 三本账每本列出已知金额项与待查项（未知项即尽调清单）；输出审查结论与整改/尽调建议

## B — 边界 (Boundary) ★

### 不要在以下情况使用本模块

- 方案尚处于"要不要进入这个行业"的方向期——先用市场导向决策（U16），本模块只在已有具体并购对象和方案时介入
- 小规模资产购置、门店收购等日常交易——本模块针对企业级兼并重组，小交易套全成本框架不划算
- 用户需要的是法律尽调、财务尽调、估值建模的具体技术——本模块提供决策审查框架，不替代专业尽调

### 作者在书中警告的失败模式

- **兼并七误区**（ce48，复合清单，详见E段步骤2）：唐钢被迫兼并毫不相干的唐山自行车总厂背上一亿包袱（拉郎配实例）；十几家中小企业被收走法人权"铁索连船"，周瑜火攻全部玩完（资产增值≠资本增值实例）
- **过度竞争后拒绝联合**（ce47）：天津200多家小果茶打大战，一两年几乎全完，连华旗、大亨也大伤元气——同向资金本应参股汇入优势企业，第一天即可分红利；阻力是"宁为鸡头不为凤尾"，小道理管了大道理
- **乱搞多元化**（ce37）：习酒陈兴国贷款5亿乱撒多元化，主业垮、被茅台兼并——扩张决策的战略红线

### 作者的盲点 / 时代局限

- **负债临界点 20%/50%/70% 为 2000 年前后经验参考值**（10讲原文即自述"这都是参考数据，必须根据具体情况具体研究"）：利率环境、行业景气、资本市场工具均已剧变，今天只能作风险提示锚点，不能作硬性否决线。
- **德隆案例后续校注**：教程盛赞的资本运营样板德隆系于 2004 年崩盘（资金链断裂、违规操作），教程成书时未载；引用教程中资本运营正面案例时须提示"成书于 2000 年，部分样板企业后续暴雷，方法本身（全成本、三原则）与涉事企业的违规操作应分开评价"。
- 案例（海尔、康佳、福田、邯钢）均带国企转轨与短缺经济尾声色彩；"政府干预但要符合经济原则"的微妙平衡是转轨期特定议题，今天审查跨境并购、民企并购时适用性有限。
- 七误区中"兼并是资本主义丑恶现象""被兼并=败家子"等观念在今天的商业语境已基本消失，扫描时可降权处理，重点保留④低成本扩张、⑤拉郎配、⑦拼规模三条。

### 容易混淆的邻近方法论

- **现代并购尽调/估值方法（DCF、可比公司法、法律财务税务尽调）**：本模块管"动机对不对、账算没算全"的决策层审查，不替代估值与尽调技术；正确顺序是先过本模块三原则七误区，再进专业尽调。
- **本书作者"成果转化六模式/搭车转化"**：本书作者讲技术方借企业产能变现（轻资产搭车），秦讲企业间产权重组（重资产整合），同样是"借助现有企业"，一个是合作、一个是并购，交易性质不同。
- **反垄断/竞争政策审查**：本模块只从企业增值角度审查，不含监管合规视角；达到申报标准的交易另需反垄断申报判断。
