# M02 · 创新与创造分野定位

> 归属：创新之门 — 第 1 关 · 定方向
> 关内作用：给个人/单位/活动定位：该做创新还是做创造，别站错队
> 用法：由总入口 SKILL.md 路由到本模块后，按 E 段步骤执行，按各模块「交付物与完成标准」出件。

## I — 方法论骨架 (Interpretation)

"创新"和"创造"在日常语言里被混用，但作者把它们拆成两种完全不同的活动，用七个维度对照：

| 维度 | 创造 | 创新 |
|---|---|---|
| 领域 | 科技领域，不追求市场效益 | 经济领域，追求效益 |
| 过程 | 从无到有（研究未知） | 从有到用（研究已知怎么用） |
| 动机 | 好奇心 | 社会需求 |
| 目的 | 技术进步 | 经济收益 |
| 风险 | 高，可能成可能不成 | 低，结果可预见 |
| 衡量标准 | 学术水平 | 经济效果 |
| 实施主体 | 院校、科研院所、专家 | 企业、一线人员 |

这个分野的实际用途是**定位**：先搞清楚一件事/一个人/一家单位该往哪边站，再谈怎么做。企业只能搞创新（风险结构决定它承受不起未知），院校适合搞创造（评价与资源体系决定它搞不了创新），两边硬凑就是"拉郎配"。方向错了，干劲越大损失越大。

## A1 — 应用示例 (Application Example)

### 示例 1: 石墨烯、量子通信——创造性劳动被当成创新
- **类型与来源**: 原书转述/评论性案例（reported_case），见《创新和创造的区别.md》第 30 行、《二十一世纪技术创新的理论与实践V2.md》（cases.md zw-12、zw-21）
- **问题/输入**: 石墨烯、量子通信被宣传为"国家创新成就"，该如何定位？
- **方法论的使用**: 套七维分野——技术不成熟（从无到有）、非市场推动、价值兑现在几年十几年后、由科研单位实施——全部落在"创造"一侧。
- **结论**: 它们完成的是创造性劳动，不是创新；拿创新的标准（短期经济效益）去要求它们是错配，拿它们充当"创新样板"同样是错配。
- **结果**: 评论性引用，原书未给具体数据（注：此为书中立场性论断，见 B 段盲点）。

### 示例 2: 冰箱从单门到三门——渐变式创新
- **类型与来源**: 原书转述案例（reported_case），见《创新和创造的区别.md》第 20、22 行（cases.md zw-23）
- **问题/输入**: 家电行业几十年没有"发明"，算不算创新？
- **方法论的使用**: 套分野——用的是成熟技术（从有到用）、由市场需求推动、效果立竿见影、实施主体是企业一线——全部落在"创新"一侧。
- **结论**: "从 1 到 1.5 到 1.6"的渐变提高是典型创新，不需要"从 0 到 1"。
- **结果**: 行业演进事实（定性），国产家电综合成本与性价比反超被仿对象（原书所述）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个模块？

1. 企业老板/技术负责人纠结"我们该自己搞研发攻关，还是用现成技术做产品"。
2. 科研单位/高校人员想转化成果，想弄清自己该扮演什么角色。
3. 政府或园区在规划"校企合作""产学研"项目，想判断这种撮合有没有戏。
4. 个人职业选择：是走科研路线（读博进院所）还是走工程/创业路线。
5. 评审材料里"创新""创造"混用，需要把两类成果分开评价。

### 语言信号 (用户的话里出现这些就应激活)

- "创新和创造有什么区别"（difference between innovation and invention/creation）
- "企业要不要搞研发 / 建实验室 / 攻关前沿技术"（should our company do R&D）
- "校企合作 / 产学研靠谱吗"（industry-university collaboration）
- "科研院所的成果为什么转化不了"（why can't research results be commercialized）
- "我适合搞科研还是做产品 / 创业"

### 与相邻模块的区别

- 与 M01 创新三要素判定器 的区别: 三要素卡判定**单个项目**的性质（是不是创新、缺哪要素）；本模块给**人/单位/活动**定位方向（该做创新还是创造、别站错队）。
- 与 M07 创新能力三支柱评估 的区别: 模块评估"这个人/团队有没有创新的本事"（知识/实践/执行三支柱）；本模块回答"该不该走创新这条路"，是能力评估之前的路口选择。

## E — 可执行步骤 (Execution)

**必需输入**: 待定位的对象（一个人/一家单位/一项活动），以及其身份属性（企业、院校、个人、政府平台等）与目标诉求（要经济回报还是要学术成果）。若对象身份与诉求不明，必须先问——同一个项目挂在企业名下和挂在院校名下结论相反。

**交付物与完成标准**: 七维对照表（逐项落"创造侧/创新侧"）+ 定位结论 + 一句行动建议。定位结论为三选一：该做创新 / 该做创造 / 当前属于主体错配须调整。

1. **判定活动性质**
   - 把待定位的活动按七维逐项打钩：研究未知还是应用已知？追求论文还是收益？结果可不可预见？
   - 完成标准: 七维中至少五维明确落侧，判定活动属"创造"还是"创新"；打不出钩的维度标注"信息不足"。

2. **判定主体属性与匹配度**
   - 企业（经营性组织）→ 应做创新；院校/科研院所 → 应做创造；个人 → 看其资源与目标，无资金承受力者不碰创造式冒险。
   - 完成标准: 输出"主体—活动"匹配判定：匹配 / 错配（企业做创造=找死；院校做创新=无动力无基础无优势）。

3. **给定位与行动建议**
   - 匹配则给执行方向建议；错配则给调整建议（如企业停掉前沿攻关改用成熟技术、院校成果交给企业做转化而非自己办厂、"校企合作"改为各归各位的分工而非联合攻关）。
   - 完成标准: 结论可直接回答用户"我该做哪边、现在这事错在哪"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用本模块

- 评价具体某项科研成果的学术价值——本模块只定方向不评高下。
- 国家层面的科技战略讨论——"院校不该做创新"是作者立场，不宜直接外推为政策结论（见盲点）。
- 用户要的是创新三要素对某个项目的逐项判定——那是 M01 创新三要素判定器 的活。

### 作者在书中警告的失败模式

- **企业搞创造是找死，不搞创新是等死（ce02）**：企业拿百分之几的利润去搞未知前沿科研，风险不可控，"高新技术企业死亡比例很高"正因此。
- **创新主体错认（ce04）**：把创新任务布置给没有市场动力的科研单位，成果与需求两张皮。
- **院企合作"拉郎配"（ce05）**：强行撮合院校与企业"合作创新"，噱头比成果多，常沦为套取补贴的工具。

### 作者的盲点 / 时代局限

- 书中强烈否定院校/前沿科研的经济价值（"863 直接作用不大""量子通信是创造不是创新"），属其立场而非普适结论（BOOK_OVERVIEW 第 3 节）；前沿科研的长期价值（如量子、AI 基础研究的后来产业回报）被其框架系统性低估。
- 二分法解释不了"从创造到创新"的接力（颠覆式创新往往需要创造先行、创新跟进），也解释不了企业内设研究院的成功案例（如贝尔实验室、华为 2012 实验室）。
- 对民间发明家态度前后不一（正面引导 vs 斥为妄想家）。

### 容易混淆的邻近方法论

- 与创新三要素判定：前者给主体定向，后者给事项定性。
- 与"技术成熟度等级（TRL）"评估：TRL 是连续刻度，本模块是二元分野+主体匹配，用途不同。
- 与"基础研究/应用研究/试验发展"的科研统计分类：那是经费统计口径，本模块是行动方向决策口径。
