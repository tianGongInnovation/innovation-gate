## I — 方法论骨架 (Interpretation)

技术方转化成果时，获利方式不是卖断技术，而是设计一套"先写进结构里"的分配与退出安排。骨架有四点：

1. **合作形态**：不自己建厂建团队，而是找一家手里有真实市场、有产能渠道的现有企业承接，资金方出钱、技术方出技术、企业方出产能与市场，三方各投所长（"你把钱投给他，我把技术投给他"）。BOOK_OVERVIEW 将这一模式概括为"搭车转化"——注意"搭车"二字是整理者的概括词、原文未出现，使用时应注明。
2. **技术方获利**：以技术入股（参股而非投现金），技术股权是主要获利载体；项目价值显现后可通过转让、引进新投资人等方式分批变现。
3. **中间人/居间方获利**：撮合成功后赠送技术干股作为居间报酬，一事一议。
4. **预设退出**：合作之初就约定回购条款——中间人或合作方想退出时，由技术方或合作方按原价或约定溢价回购，"好合好散"；也可选择继续持有、部分套现部分保留。

核心思想：怎么挣钱、怎么退出，在合作开始时就写进结构，而不是等项目做成了再争。

## A1 — 应用示例 (Application Example)

### 示例 1: 中间人居间撮合的干股+回购演练
- **类型与来源**: 原书未提供展示完整获利结构落地的独立案例（江天重工案例只交代了改造费与运营结果，未披露股权安排），以下为按原书规则的**合成演练**，仅用于复算规则，不代表作者经历或现实结果。
- **问题/输入**: 中间人 A 把技术方 B 的节能技术介绍给企业 C，三方谈合作。A 问"我怎么获利、以后怎么退出"。
- **方法论的使用**: 按原书规则设计——A 不出资，撮合成功后 B 赠予 A 一定比例技术干股（比例一事一议，按各方付出的资源与心血谈）；C 也可能因感谢撮合赠予少量股权。协议中写入退出条款：项目价值显现后，A 可选择①继续持有等增值；②全部或部分转让给 B、C 或新进入的投资人；③要求按约定（原价或溢价）由 B 或 C 回购。
- **结论**: A 的获利载体是干股而非现金佣金，退出路径在签约时已锁定，双方风险可控（A 无投入、亏不到哪去；B/C 保留了股权回收通道）。
- **结果**: 合成演练，无现实结果；可复算的规则点是"赠股—持权—约价回购"三步结构。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个模块？

1. 用户有技术/专利，正要与企业或资金方谈合作，纠结"我该要现金、要股权还是收服务费"。
2. 用户是中间人/居间人，帮人撮合了技术合作，不知道怎么开口要报酬、要"干股"合不合适。
3. 合作谈成了，用户在起草利益分配条款，问"股权怎么分、以后谁想退出怎么办、要不要写回购"。
4. 有人提议"咱俩成立公司、建厂生产"，用户犹豫要不要走这条重资产路线。
5. 项目做成了开始值钱，早期参与方想套现离场，用户问"退出怎么安排才不散伙不翻脸"。

### 语言信号 (用户的话里出现这些就应激活)

- "技术入股怎么谈 / 技术股值多少钱 / equity for technology"
- "居间费 / 中介费怎么要 / 要不要给介绍人干股 / finder's fee"
- "退出机制 / 回购条款 / buy-back / 好合好散怎么写"
- "要不要成立公司建厂 / 自建团队还是借现有企业"
- "股权怎么分 / 赚钱了怎么分 / profit sharing structure"

### 与相邻模块的区别 

- 与 M08 技术方-企业合作落地流程（技术方-企业合作落地流程）的区别：流程卡管"怎么谈成"（三前提、六步、差旅红线）；本模块管"谈成后怎么分钱、怎么退出"的结构设计。流程走到起草协议阶段时切换到本模块。
- 与 M11 合作协议条款审查清单（合作协议条款审查清单）的区别：本模块产出的是商业结构方案（给谁什么股、怎么回购）；清单卡是把已定结构落成协议文本时的 12 类条款核对表。先结构、后文本。

## E — 可执行步骤 (Execution)

**必需输入**:
- 参与角色清单（技术方/资金方/企业方/中间人，各方出什么：技术、钱、产能、市场、撮合）；
- 项目的市场证据（有无订单级真需求，见 M06 创新项目筛选器 / 真假需求判据）；
- 各方对获利形式与期限的预期（要现金还是要股权、急不急套现）。
- 缺"项目是否已有真实市场承接方"时必须先问——没有承接企业的，不适用三方结构，应回到找项目/找合作方环节，不能静默假设。

**交付物与完成标准**: 输出一份《获利与退出结构方案》，含：①角色-投入-回报对照表（每方一行，写明投入物与回报载体）；②股权/干股比例区间（标注"一事一议，比例需各方谈判确定"，不给虚构基准值）；③退出条款要点（回购触发条件、定价方式：原价或约定溢价、可部分套现）；④不适用警示。完成标准：每个参与方都能从表中读出"我出什么、拿什么、怎么退"。

被路由到本模块后，按以下步骤执行：

1. **定合作形态**
   - 检查是否存在"有真实市场 + 有产能渠道"的现有企业作为承接方；有 → 采用三方合作结构（资金方出钱、技术方出技术、企业方出产能市场）。
   - 完成标准：三方角色及其投入物一一对应列出。
   - 判停条件：若方案出现"成立新公司、建厂房、招团队从零干"（ce18 警告的重资产老路）→ 显式提示该路径违背作者"借助现有企业体系"原则，要求用户确认是否有特殊理由，否则改回三方结构；若根本没有承接企业 → 停止结构设计，转项目筛选/找合作方流程。

2. **配获利载体**
   - 按角色配回报形式：技术方 → 技术入股（参股不投现金）；中间人 → 赠予技术干股（居间报酬）；资金方 → 股权增值；企业方 → 产品利润与竞争力。比例标注"一事一议"。
   - 完成标准：对照表中无"待定"之外的角色，且没有任何一方被要求"先掏大额现金换不确定收益"（作者原则：居间方和技术方不以现金投入为前提）。

3. **预设退出条款**
   - 写入三类安排：①回购——任一方想退出时由技术方或合作方按原价或约定溢价回购；②分批变现——可全部转让、部分套现部分保留；③引进新投资人时的退出窗口。同时写明"好合好散"原则（终止不伤感情、不诉诸对抗）。
   - 完成标准：退出条款含触发条件、定价方式、承接方三要素；并提示用户将该结构交 M11 合作协议条款审查清单 落成协议条款。

## B — 边界 (Boundary) ★

### 不要在以下情况使用本模块

- 技术尚未过"短平快 + 真市场"筛选（ce15：长周期、大投资、高风险项目不适用此结构——结构的前提是项目本身符合筛选纪律）。
- 面向"拿国家课题经费"的项目（ce14：经费导向、结题即终点的项目没有市场分配问题，套股权结构是空谈）。
- 涉及复杂公司法/证券合规的交易（上市公司并购、对赌协议设计等）——作者的经验是民间项目层面，不构成法律与投资意见。

### 作者在书中警告的失败模式

- **自建团队厂房的重资产老路**（ce18）："有钱+有技术就成立工厂建团队，没有几年时间根本干不了"——等产能出来市场早变了；正确做法是把钱和技术投给有市场有产能的现有企业。
- **技术垄断思维**（ce25）：试图靠专利独家垄断、漫天要价，会招致行业联合绞杀（澳大利亚无限景深镜头发明人破产案）；作者的对策是合作共赢、合理分成，"垄断没有出路"。
- **发明人的全能幻觉**（ce34）：技术持有人试图独自完成技术+市场+资金全链条，样样稀松；必须分工，各就其位。

### 作者的盲点 / 时代局限

- **财务颗粒度粗**（BOOK_OVERVIEW 第 3 节）：作者只给结构不给数字——干股比例、溢价幅度、估值方法均无基准值，"一事一议"之外的具体测算需用户自备财务顾问。
- 作者"几百项专利"与产业落地之间的转化实例基本空白（BOOK_OVERVIEW 第 3 节），本结构主要来自作者单方经验陈述，缺少失败案例的系统复盘，使用时应按"经验假说"对待。
- 动员话术需剥离："翻十倍、翻一百倍"类表述是动员语言，不得作为收益预期输出。

### 容易混淆的邻近方法论

- 与秦骏伦"资本经营"混淆：秦讲的是企业层面参股控股、并购重组（董事会视角）；本模块是技术持有人/中间人在单个项目上的分配安排，不是资本经营。
- 与标准技术许可（licensing）混淆：许可是一次性/按期收取许可费；作者的结构以股权为载体、以回购为退出，不主张卖断或许可费模式。
- "搭车"一词易误用：此词为整理者概括（g36 / 勘误 12），原文说法是"借助现有企业的研发、生产、销售体系"，引用原文时不得标注"搭车"为原文。
