# 体系概览

> 读这一份，是为了知道整套方法的来历、骨架和它管不了的事。干活请回到 SKILL.md 的路由表。

## 这套方法讲什么

一句话主旨：**创新 = 成熟知识结合真实具体需求的实践应用**，三要素缺一不可。围绕这一句，展开"怎么判断、怎么找方向、怎么筛项目、怎么做、怎么合作转化、怎么获利"的全套实操方法。

它要解决的核心问题：创新被普遍讲成"新、高、尖端"，导致企业、科研单位和个人把创造当创新干，钱花了、东西做出来了，却没人要——方向错了，干劲越大损失越大。

## 骨架（七个部分，递进关系）

1. **定义与分野**：创新三要素（成熟技术 / 真实需求 / 具体行动）；创新与创造的七维分野（从无到有 vs 从有到用）。
2. **主体与动力**：创新是一线人员和企业的事；需求是动力，要会辨真假需求（能签单、能控制才是真需求）。
3. **创新推理方法**：基础理论再认识（回到理论原文）、应用理论再发展（与时俱进）、突破惯性思维、跨界交叉应用。
4. **项目筛选纪律**：短平快四特征（投资小 / 周期短 / 风险低 / 市场真）、十条找项目规则、负面清单。
5. **合作与转化流程**：企业合作三前提、六步推进流程、节能调研七步法、搭车式转化、技术入股获利结构。
6. **孵化运营模式**：金蛋理论（平台要有自有项目）、股权三阶段、轻资产纪律、合作协议条款清单。
7. **经营诊断（辅线）**：传统经营 vs 创新经营七区别、自然经济十四种表现、市场导向五组关系、兼并三原则七误区。

## 八条核心命题

1. 判定是不是创新只需逐一套用三要素，缺一不可。
2. 企业只能搞创新，搞创造是找死；院校适合创造不适合创新，两者硬凑是拉郎配。
3. 拿着技术找市场是方向错误；必须以市场和问题为导向，先辨真假需求。
4. 技术创新的推理可复用：回到理论原文 → 追问手段与目的 → 用时代条件差找切入点 → 数值对比 → 跨界平移成熟技术 → 落地三问验证。
5. 项目必须短平快：投资小、周期不超一年、技术成熟、有真订单，否则不做。
6. 转化靠搭车：不自建团队厂房，技术入股借现有企业的产能和渠道变现，好合好散、预设退出。
7. 孵化与园区的命脉是自有项目和清晰的获利结构，不是房租差价。
8. 经营的核心是决策，决策的核心是创新；市场可行性排第一。

## 关键术语（本体系特有口径）

| 术语 | 这里的含义 | 与常识用法的差异 |
|---|---|---|
| 创新三要素 | 成熟的东西 + 真实的需求 + 具体的行动 | 常识强调"新"，这里强调"成熟 + 真需求" |
| 成熟技术 | 人人都在用、用到不值钱、反复验证过的技术 | 常识认为创新要用高新技术，这里相反 |
| 真需求 / 假需求 | 真需求 = 能签约、能控制、能落地；假需求 = 看得见抓不住；主观需求 = 长官意志 | 把"需求"收窄成可验证的订单 |
| 从有到用 / 从无到有 | 创新 vs 创造的过程本质 | 常识把两者混用 |
| 偷工减料 | 中性方法词：降本增效的合理化手段 | 常识是纯贬义 |
| 回到初心 | 打破历史局限，回到理论本源重新选技术路径 | 常识是励志用语，这里是推理步骤 |
| 金蛋理论 | 园区必须有自有项目（蛋），否则只是有鸡窝的房东 | 对"孵化器等于物业"的批评 |
| 节能必须节钱 | 节能不节钱，宁可不节 | 节能领域的实效判据 |

## 这套方法管不了什么（重要）

- **时代局限**：经营诊断部分成文于二十年前后，案例带国企转轨色彩，用于今天的民企、外企、互联网企业须先翻译语境。
- **立场性判断**：书中强烈否定前沿科研与院企合作的经济价值，属一家之言，不宜直接外推为政策结论或普遍结论。
- **未经检验的主张**：成功率、节能倍数等卖点数据多为自述，无第三方实测与统计检验；热泵开水器等得意项目的市场跟进情况并不能证明"通过判据就等于成功"。
- **最强反对意见**：三要素框架能解释增量式改进，解释不了依赖不成熟技术、需要被创造出来的需求的颠覆式创新（智能手机、电动车产业即属此类），按本体系的判据，它们在立项期都会被否决。本体系只排雷，不承诺中奖。
- **须降级采信的结论**：语料中涉及"突破基础定律"式的热力学推论、以及质疑气候科学主流共识的论述，与科学界主流认识冲突，方法可用、结论必须分开标注，不得当作既定事实使用。

> 使用时：相信方法，对结论保留分级。所有对客户的测算与承诺，另行核实数据。
