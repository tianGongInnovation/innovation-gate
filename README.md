# 创新之门（innovation-gate）

技术创新全程导航：从一个念头到把技术创新做成，中间每一步该怎么判断、怎么做。以"创新三要素"（成熟的东西 + 真实的需求 + 具体的行动）为总判据，按六道关路由到十六个能力模块。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**（署名即可自由使用、修改、分发）。

## 有什么用处？

- 手上有想法、点子、项目、专利，或企业抛来合作意向，拿不准"该不该做、先干哪一步"时，给出判断路径
- 先过第 0 关三要素总判据（缺一否决），再按处境路由到对应的一关：定方向、找方向、筛项目、进企业、谈条件、做决策
- 十六个模块彼此衔接，上一关的结论直接是下一关的输入；每关给判据、给清单、给判停线

## 为什么要用？

创新最常见的损失，不是做不成，而是方向错了还干劲很大。市面上讲创新多讲情怀，落到手上还是不知道第一步干什么。本技能把"该不该做"变成可照做的判断流程，不靠感觉拍脑袋。

## 如何用？

1. 为 WorkBuddy 等智能体准备：安装到技能目录后，说出你的问题（技术是什么、需求是谁的、现在到哪一步）
2. 智能体先过第 0 关，再路由到对应关卡并加载该关模块，输出判定表、清单或报告框架
3. 也可人工阅读 `SKILL.md` 与 `references/` 下对应模块，按步骤自行判断

## 有问题怎么办？

- 判据用不通、结论不放心 → 回到第 0 关重判，多半是某一要素的信息没给全
- 觉得结论太武断 → 本技能是"快速否决器"，目的是少赔钱，不是保证成功；它排雷，不承诺中奖
- 需要原文依据、案例和反例 → 读 `references/` 下对应模块，每个模块都带原文引句、正反案例和边界说明
- 超出覆盖范围（法律条款效力、财务尽调、合规审计）→ 转专业人员，不要硬套
